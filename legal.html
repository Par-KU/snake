Documentos legales de Snake Retro

Esta página describe el tratamiento de datos y las condiciones de uso de la versión de demostración de Snake Retro.

Última actualización: octubre de 2026.

1. Aviso de privacidad

Responsable del proyecto: el responsable que administra la instancia de Snake Retro utilizada por el jugador. Esta versión se ejecuta en un entorno local de demostración.

¿Qué datos se recopilan?

  • El apodo elegido por el jugador, de hasta 18 caracteres.
  • Un identificador aleatorio que permite asociar partidas desde el mismo navegador.
  • La puntuación, el tiempo de supervivencia, el nivel alcanzado y la fecha de cada partida registrada.
  • Datos técnicos que puedan aparecer en los registros del servidor, como la dirección IP y la fecha de una solicitud.

¿Para qué se utilizan?

Los datos se utilizan para registrar partidas, mostrar las clasificaciones por puntos y supervivencia, calcular la clasificación semanal, mantener el historial de resultados y comprobar el funcionamiento del proyecto.

¿Se solicitan contraseñas?

Esta versión no requiere crear una cuenta ni introducir una contraseña. El identificador aleatorio del navegador no verifica la identidad real de una persona. Se recomienda utilizar un apodo que no revele información personal.

Almacenamiento y protección

El identificador del jugador se guarda en el almacenamiento local del navegador. Las partidas registradas se guardan en la base de datos de la instancia que opera el servicio. La configuración de demostración utiliza HTTPS local y controles de seguridad del servidor; esto no implica que los datos estén cifrados en reposo.

Conservación y solicitudes

En esta versión de prueba, los registros se conservan mientras permanezcan en la base de datos de la instancia. Borrar los datos del navegador elimina el identificador local, pero no borra por sí mismo las partidas almacenadas en el servidor. Para solicitar la revisión o eliminación de datos, debe contactarse a quien administre la instancia utilizada.

Alcance de este aviso

Este aviso describe la versión de demostración local. Antes de publicar el servicio para usuarios externos, el responsable deberá revisar y actualizar este documento conforme al funcionamiento real del servicio, las medidas aplicadas y las obligaciones legales que correspondan.

2. Términos y condiciones

Uso permitido

Snake Retro se ofrece como un juego de entretenimiento y como proyecto de demostración académica. El usuario puede jugar, elegir un apodo y consultar las clasificaciones disponibles.

Responsabilidades del usuario

  • Utilizar apodos apropiados y evitar publicar datos personales.
  • No intentar acceder sin autorización a servidores, datos o funciones ajenas a la aplicación.
  • No interferir intencionalmente con la disponibilidad o el funcionamiento del servicio.
  • Comprender que las puntuaciones enviadas no cuentan con una verificación completa contra trampas.

Disponibilidad y datos

La aplicación se encuentra en desarrollo y puede sufrir cambios, interrupciones, reinicios o pérdida de registros. Las clasificaciones son informativas y pueden modificarse si se reinicia o mantiene la base de datos.

Limitación de responsabilidad

La versión de demostración se proporciona con fines de prueba y aprendizaje, sin garantía de disponibilidad continua ni de ausencia de errores. El responsable de la instancia deberá atender las responsabilidades que legalmente no puedan excluirse.

Actualizaciones

Estos términos pueden actualizarse a medida que evolucione el proyecto. El usuario debe consultar esta página para conocer la versión vigente.
